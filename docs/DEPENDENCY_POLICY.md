# Dependency upgrade policy

Обновление версий зависимостей (инфраструктура, JDK, библиотеки) — по [ADR-0004](adr/0004-dependency-version-pinning.md).

## Правило

- Все критические зависимости зафиксированы (pin); использование `latest` запрещено.
- Файл `versions.lock` (или аналог в репозитории) — единственный источник пинов для сборки и деплоя.

## Процедура обновления

1. Внести изменение в `versions.lock` (и при необходимости в Docker/Helm/Gradle).
2. Оформить ADR или дополнение к ADR-0004 с обоснованием и указанием версий.
3. Прогнать CI (build, smoke/integration).
4. Иметь план отката (предыдущее состояние `versions.lock`).

## Пересмотр

- При срабатывании триггеров из ADR-0004 (безопасность, требования enterprise).
