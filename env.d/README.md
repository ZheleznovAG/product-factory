# env.d — переменные окружения для сборки и запуска

Один файл = одна переменная (имя файла = имя переменной, содержимое = значение).

## Настройка один раз (direnv)

1. Установите [direnv](https://direnv.net/) и подключите к shell (см. документацию).
2. Скопируйте пример и при необходимости поправьте путь к JDK 17:
   ```bash
   cp env.d/JAVA_HOME.example env.d/JAVA_HOME
   ```
3. В корне проекта один раз выполните: `direnv allow`.

После этого при каждом `cd` в каталог проекта `JAVA_HOME` и остальные переменные из `env.d/` подхватываются автоматически — ничего вызывать не нужно. Сборка: `./gradlew build`.

**Без direnv:** создайте `env.d/JAVA_HOME` вручную и запускайте команды через `./scripts/run-with-envdir.sh gradle build --no-daemon`.

В CI переменные задаются в workflow, не из `env.d/`. Файл `env.d/JAVA_HOME` не коммитить (в .gitignore).
